# 2026-08-09 工作日志

## 修复三张牌的 bug
1. **决斗回合挂起**：决斗中打不出杀的一方受伤害后，原代码 `_resumeSourcePlay(challenger)` 恢复的是"上一个出杀者"，导致 AI 发起决斗→玩家反击→AI 无杀时 AI 回合永久挂起（人类恢复分支为空操作）。修复：3 处（03-cards.js humanRespondJuedou/humanRespondJuedouSecond、ai.js aiRespondJuedou）统一改为恢复 `players[currentPlayerIdx]`（当前出牌方）；02-turn.js resolveAutoPlayPending 的 juedou case 同步修正。
2. **过河拆桥/顺手牵羊盲选卡死**：盲选模式（出牌者是人类）UI 只有手牌按钮，目标无手牌只有装备/判定区时无法选择→卡死。修复：08-ui.js 盲选按钮区补装备（slotNames）+判定区按钮，复用 humanGuoheDiscardEquip/Judge、humanShunshouStealEquip/Judge。
3. **顺手牵羊判定区牌处理错误**：原代码把判定区原卡 push 进弃牌堆再生成无 ownerId 副本。修复：直接 splice 移入手牌并设 ownerId。
4. **顺带**：AI 顺手牵羊加距离限制（calcDistance≤1）；新增统一 `cancelWait()` 替换所有内联取消按钮，防止取消导致 AI 回合挂起。
