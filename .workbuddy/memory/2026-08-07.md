# 2026-08-07 工作记录

## 三国杀网页版 — 技术美术优化（视觉质感与打击感优先）
- 项目性质：纯前端 DOM+CSS 卡牌游戏，无图片资源，全部视觉靠 CSS 渐变/阴影。
- **关键约束（重要）**：`game.js` 的 `_doRender()` 每帧用 `innerHTML` **整块重建** `#app`。因此所有瞬时特效不能进游戏 DOM（会被重建清掉/重启动画）。
- 落地改动：
  - 新增 `vfx.js`（特效引擎，`VFX.fire(type, playerId)`：伤害环+火花+全屏红闪+震屏 / 治疗绿脉冲 / 技能金光爆发；仅 transform/opacity，短生命周期自清理）。
  - `index.html` 加 `#vfx-layer` 覆盖层并引入 vfx.js。
  - `game.css`：全局 SVG 颗粒噪点（body 背景层 overlay 混合）、hero 面板 GPU 回合光晕（替代动 box-shadow 的 panelGlow）、卡牌金属斜边+悬停箔面流光、全套 VFX keyframes、三处 backdrop-filter 模糊下调（4/3/2 → 3/2/1.5px）。
  - `game.js`：`renderHeroPanel` 加 `id="hero-{id}"`；新增 `triggerVFX()`；`dealDamage` 末尾挂伤害+震屏（唯一伤害漏斗）；`resolveTao` 挂治疗；奸雄/天妒/雷击/火攻 挂技能光爆。
- 本地预览服务：端口 8123（`python -m http.server`）。

## 复用提示
- 后续加任何游戏内瞬时视觉反馈，统一走 `#vfx-layer` + `VFX.fire`，不要在游戏 DOM 里加。
- 若想做"卡牌飞入/出牌动画"，需配合渲染层改造（避免 innerHTML 重建重启动画），单独排期。
