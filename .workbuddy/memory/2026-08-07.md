# 2026-08-07 工作记录

## 项目约束（三国杀网页版，纯 DOM+CSS 渲染）
- `#app` 每帧 `innerHTML` 整块重建（game.js `_doRender`）。因此：
  - 瞬时打击感特效必须放独立 `#vfx-layer` 覆盖层（vfx.js），由事件点召唤、自动销毁，绝不进游戏 DOM。
  - 所有动效只用 `transform`/`opacity`，走 GPU 合成，避免每帧重绘/重排。

## 本次优化：座位呈现 → 椭圆环形桌位
- 原 `players-grid` 平铺网格改为 `.seat-table` 椭圆环形：人类固定桌底(180°)，其余按座位号均匀环绕，JS 注入 `--x/--y` 百分比极坐标（相对桌宽/高），`left/top calc(50% + var)` + `transform: translate(-50%,-50%)` 定位，自适应缩放。
- 牌堆居中桌心 `.table-center`，加「出牌顺序 ↺」流向提示。
- 人类手牌/装备拆到环形外的 `.human-tray` 底部独立横条（避免环形槽位溢出）。
- `@media (max-width:850px)` 降级为 grid 平铺。
- 改动文件：game.js（render 座位段）、game.css（seat-table/table-center/player-slot/human-tray + 降级）。
